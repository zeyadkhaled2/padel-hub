THIRD-PARTY OPEN-SOURCE NOTICE — libheif-js / libheif / libde265
==================================================================

Raketna uses `libheif-js` (version 1.23.5), an Emscripten WebAssembly build
of `libheif` and `libde265`, solely as an optional on-demand browser fallback
to decode HEIC/HEIF camera photographs when native browser decoding is not
available.

Standalone Dynamic Loading & Modification / Replacement (LGPL-3.0 §4(d))
------------------------------------------------------------------------
The unmodified upstream ES module is served separately from Raketna's
application code at:
  /vendor/libheif/libheif-bundle.mjs

Raketna loads this file dynamically at runtime via standard ES module
`import()` only when needed. No restriction is placed on modifying or
debugging the library portions, and any interface-compatible build exposing a
default export factory returning `{ HeifDecoder }` may be substituted at
`/vendor/libheif/libheif-bundle.mjs` (including via browser local overrides or
self-hosted replacement) without rebuilding Raketna.
