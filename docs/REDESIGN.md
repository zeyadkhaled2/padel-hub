# Courtside redesign — 2026-11-14

Ziad requested a substantial replacement of the previous muted, CSS-illustrated design, plus a Padel Hub logo. Audience: Egyptian padel players browsing equipment; primary action: find equipment and inspect its condition and seller.

Plan before implementation: cobalt court blue, warm yellow hero, coral highlights, white surfaces and navy text; dark mode uses navy surfaces. Retain system typography with Arabic fallbacks, heavier short headlines and prominent EGP prices. Compact split hero, realistic equipment artwork, full-width search and category links before the product grid. Mobile keeps search early, with a compact image. A perforated racket and yellow ball form a custom SVG brand mark, paired with the Padel Hub wordmark. No new marketing claims or backend actions.

Generated unbranded equipment imagery replaces CSS drawings; labels must explain it does not depict actual inventory or named product models. Canva was evaluated as an optional aid; built-in image generation provides local project artifacts without a dependency on a hosted Canva design. All browsing remains server-rendered and URL-based.
